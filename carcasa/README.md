# Carcasa

Diseño 3D de la carcasa. Pendiente de la fase 6.

Requisitos:

- Ventana redonda para la pantalla de 1,28" (zona visible 32 mm; el módulo es algo mayor). Referencia de diseño en [docs/img](../docs/img).
- Pared fina (2–3 mm) en la zona del sensor táctil, para que detecte el dedo a través del plástico.
- Rejilla pequeña o ranura para el altavoz.
- Acceso al USB-C para alimentarlo y programarlo.
- MPU6050 bien sujeto (si se mueve dentro, detectará golpes falsos).
